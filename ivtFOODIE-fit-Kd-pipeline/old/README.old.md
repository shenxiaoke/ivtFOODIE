# input

- species (human, mouse, etc.)
- samples ratio files
- sample concentration for each file
- PC ratio files
- motif file (optional)

# output

- single-C Kd
- de novo footprints with vary Kd thresholds
- use streme to enrich motifs for each footprints set
- fimo scanned sites for each streme-enriched motif
- conversion ratio for different concentration samples for each motif-derived sites
